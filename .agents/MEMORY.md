- On Windows, a full parallel `cargo test` may exhaust the page file while mmap'ing `libcc_switch_lib.rlib` (`os error 1455`) and trigger cascading rustc ICEs. Retry with `CARGO_INCREMENTAL=0`, `-j 1`, and `--test-threads=1`; symlink tests still require Developer Mode/elevation, and the running app may occupy port 15721.
- The upstream Windows+WSL2 CI contract can intermittently relink after `TEMP`/`TMP` switch to a WSL UNC path and fail in `mt.exe` with `LNK1327`/`c1010070`. This fork performs real LLM streaming checks, so return an explicit unsupported error and keep the action hidden until the app has a real parser/protocol route (as of 2026-09-17, MiniMax Code / `mcode` is intentionally guarded this way).
