- Networked CLI commands must use the explicit per-command proxy `http://127.0.0.1:2235`; do not set persistent global proxy environment variables.

- On Windows, a full parallel `cargo test` may exhaust the page file while mmap'ing `libcc_switch_lib.rlib` (`os error 1455`) and trigger cascading rustc ICEs. Retry with `CARGO_INCREMENTAL=0`, `-j 1`, and `--test-threads=1`; symlink tests still require Developer Mode/elevation, and the running app may occupy port 15721.
- The upstream Windows+WSL2 CI contract can intermittently relink after `TEMP`/`TMP` switch to a WSL UNC path and fail in `mt.exe` with `LNK1327`/`c1010070`. If native-temp compilation and all regular platform jobs passed, rerun only the failed job once before changing code; the v3.20.0 isolated rerun passed unchanged.

- On this workstation, `commands::misc::tests::windows_path_lookup_ignores_same_named_file_in_current_directory` can fail even in isolation because `where.exe` reports no match for the test's temporary PATH. Confirm that the test body matches upstream and rely on the clean `windows-latest` CI job before changing unrelated lookup behavior.
